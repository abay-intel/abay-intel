Projects

YeAbay Wuha Intel’s 24-month Phase 1 work is organised into a web platform, a groundwater database, machine learning and flow models, and field validation. The projects below are planned and under development.

Featured

YeAbay Wuha Intel platform Planned, Phase 1

A browser-based tool for groundwater site assessment, with borehole yield and suitability predictions for any GPS coordinate and purpose-specific report templates. It is designed to work offline in the field after initial loading.

software
Integrated groundwater database Planned, Phase 1

A spatial database that brings together satellite observations, borehole records, pumping test results, climate data, and hydrogeological maps for the Abay Basin and the Amhara Region, with documented data provenance.

resource

More

AI groundwater model Planned, Phase 1

A hybrid convolutional neural network and Random Forest model for borehole yield and groundwater suitability scoring, with explanations for each prediction.

software
Groundwater flow model Planned, Phase 1

A calibrated numerical groundwater flow model for a pilot sub-catchment, used to test abstraction, land use, and climate scenarios.

resource
Field validation Planned, Phase 1

Geophysical surveys and water quality sampling at candidate sites across the Upper Blue Nile Basin, used to check model predictions against field conditions.
